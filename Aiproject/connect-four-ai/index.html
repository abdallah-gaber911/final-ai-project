📖 Rules & Algorithm Documentation

Rules of Connect Four and algorithmic foundations of Minimax and Alpha-Beta Pruning.

🎮 Game Rules & Keyboard Shortcuts

  • Connect Four is a 2-player zero-sum connection game on a 6-row × 7-column vertical grid.
  • Pieces fall directly down to the lowest unoccupied slot in the chosen column.
  • First player to align 4 consecutive pieces horizontally, vertically, or diagonally wins.
  • If all 42 slots fill with no winner, the match is a Draw.
  • ⌨️ Keyboard Shortcuts:
  • 1–7 Drop coin in column  |  N New Game
  • U Undo  |  H AI Hint

📘 Minimax Algorithm

Python Implementation

Minimax performs a full depth-first exhaustive search of the game tree. The maximizer (AI) always picks the move with the highest score; the minimizer (opponent) always picks the lowest. Every possible branch is explored up to depth d.

// ── PSEUDOCODE ──────────────────────────────────────────
function minimax(node, depth, isMaximizing):
if depth == 0 or node is terminal:
return evaluate(node)
 
if isMaximizing:
maxVal = -∞
for each child in node.children:
val = minimax(child, depth-1, False)
maxVal = max(maxVal, val)
return maxVal
else:
minVal = +∞
for each child in node.children:
val = minimax(child, depth-1, True)
minVal = min(minVal, val)
return minVal
minimax.py 
def minimax(board, depth, is_maximizing, player, stats):
    """
    Exhaustive game-tree search (no pruning).
    Returns (best_column, best_score)
    """
    stats["nodes_visited"] += 1
    opp = HUMAN if player == AI else AI

    if check_win(board, player):   # Current player won
        return None, 1_000_000 + depth
    if check_win(board, opp):      # Opponent won
        return None, -1_000_000 - depth
    if is_board_full(board) or depth == 0:
        return None, score_position(board, player)

    valid_moves = get_valid_moves(board)   # [3,2,4,1,5,0,6] center-first
    best_col    = valid_moves[0]

    if is_maximizing:
        best_score = -float("inf")
        for col in valid_moves:
            row = get_bottom_empty_row(board, col)
            drop_piece(board, row, col, player)
            _, score = minimax(board, depth-1, False, player, stats)
            undo_piece(board, row, col)
            if score > best_score:
                best_score, best_col = score, col
        return best_col, best_score

    else:    # minimizing (opponent's turn)
        best_score = float("inf")
        for col in valid_moves:
            row = get_bottom_empty_row(board, col)
            drop_piece(board, row, col, opp)
            _, score = minimax(board, depth-1, True, player, stats)
            undo_piece(board, row, col)
            if score < best_score:
                best_score, best_col = score, col
        return best_col, best_score

⚡ Alpha-Beta Pruning

Python Implementation

Alpha-Beta extends Minimax with two bounds: α (best score the maximizer can guarantee) and β (best the minimizer can guarantee). When β ≤ α, the remaining siblings cannot influence the result — they are pruned and never evaluated.

// ── PSEUDOCODE ──────────────────────────────────────────
function alphaBeta(node, depth, α, β, isMax):
if depth == 0 or node is terminal:
return evaluate(node)
 
if isMax:
val = -∞
for each child:
val = max(val, alphaBeta(child, depth-1, α, β, False))
α = max(α, val)
if β ≤ α: break // ✂ β-cutoff (prune)
return val
else:
val = +∞
for each child:
val = min(val, alphaBeta(child, depth-1, α, β, True))
β = min(β, val)
if β ≤ α: break // ✂ α-cutoff (prune)
return val
alpha_beta.py 
def alpha_beta_search(board, depth, alpha, beta, is_maximizing, player, stats):
    """
    Minimax with Alpha-Beta pruning.
    alpha = best score maximizer can guarantee  (starts at -∞)
    beta  = best score minimizer can guarantee  (starts at +∞)
    Prune when beta ≤ alpha.
    """
    stats["nodes_visited"] += 1
    opp = HUMAN if player == AI else AI

    if check_win(board, player):
        return None, 1_000_000 + depth
    if check_win(board, opp):
        return None, -1_000_000 - depth
    if is_board_full(board) or depth == 0:
        return None, score_position(board, player)

    valid_moves = get_valid_moves(board)
    best_col    = valid_moves[0]

    if is_maximizing:
        max_eval = -float("inf")
        for col in valid_moves:
            row = get_bottom_empty_row(board, col)
            drop_piece(board, row, col, player)
            _, score = alpha_beta_search(
                board, depth-1, alpha, beta, False, player, stats)
            undo_piece(board, row, col)
            if score > max_eval:
                max_eval, best_col = score, col
            alpha = max(alpha, score)
            if beta <= alpha:         # ✂ β-cutoff — minimizer won't allow this
                stats["pruned_nodes"] += 1
                break
        return best_col, max_eval

    else:    # minimizing
        min_eval = float("inf")
        for col in valid_moves:
            row = get_bottom_empty_row(board, col)
            drop_piece(board, row, col, opp)
            _, score = alpha_beta_search(
                board, depth-1, alpha, beta, True, player, stats)
            undo_piece(board, row, col)
            if score < min_eval:
                min_eval, best_col = score, col
            beta = min(beta, score)
            if beta <= alpha:         # ✂ α-cutoff — maximizer won't allow this
                stats["pruned_nodes"] += 1
                break
        return best_col, min_eval
